# Critical Council Protocol
## Адаптация LLM Council (Karpathy) под одного агента

Когда пользователь спрашивает **моё мнение** по вопросу — я применяю внутренний совет:

### Этап 1: Генерация позиций
Формирую 2-4 разных взгляда/подхода к вопросу (как если бы это были разные LLM):

- **Рациональный** — строгий, прагматичный, цифры/факты
- **Критический** — ищет слабые места, риски, контр-аргументы
- **Креативный** — нестандартные решения, смелые идеи
- **Консервативный** — проверенные подходы, стабильность

### Этап 2: Критика
Каждая позиция оценивает остальные (анонимно):
- Что упущено?
- Где слабые аргументы?
- Какие есть альтернативы?

### Этап 3: Синтез
Формирую финальный ответ, который:
1. Учитывает сильные стороны всех позиций
2. Указывает на оставшиеся неопределённости
3. Даёт взвешенную рекомендацию

---

> Применять ТОЛЬКО когда пользователь явно просит мнение/совет/оценку.
> Для фактических вопросов ("как сделать X", "напиши код") — стандартный подход.
